## 📌 О проекте

Цифровой сервис (сайт + Telegram-бот) для управления киберспортивной лигой вуза. Объединяет в одном месте расписание матчей, результаты, турнирные таблицы, составы команд, правила и регистрацию.

**Проблема:** данные разбросаны по чатам и постам, новички не понимают, как попасть в лигу, результаты теряются, организаторы тратят время на рутину.

**Решение:** единая точка входа для участников, зрителей и администраторов лиги.

---

## 🎯 Цель

Автоматизировать сопровождение студенческой киберспортивной лиги и повысить вовлечённость участников.
